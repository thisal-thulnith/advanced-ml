# Advanced ML Bootcamp

My weekly work for the Advanced ML Bootcamp. Each week lives in its own `weekNN/`
folder containing a `notes.md` summary plus any homework, assignments, or
practical implementations for that week.

## Structure

```
advanced-ml/
├── README.md      # this file
├── week01/
│   ├── notes.md   # summary of lessons learnt
│   └── ...        # homework / assignments / implementations
├── week02/
│   └── notes.md
└── ...
```

## Weekly workflow

1. Create a branch from `main` named `week<NN>-<topic>`.
2. Add a `weekNN/` folder with `notes.md` and any work for the week.
3. Commit and push the branch.
4. Raise a pull request into `main` and add the instructor as a reviewer.
5. Address feedback, then merge once approved.
